# 🍍 SpongeBob Telegram Bot

Інтерактивний Telegram-бот для дітей, занурений у всесвіт Губки Боба Квадратні Штани. Бот використовує потужність **ChatGPT (OpenAI)**, щоб створювати унікальні казки, проводити вікторини та спілкуватися з улюбленими героями Бікіні Боттом.

## 🚀 Основні функції

*   **📖 Казка-конструктор:** Створюйте власні історії, обираючи персонажа, локацію та тему. ШІ згенерує унікальну казку саме для вас!
*   **🗣 Побалакати з друзями:** Спілкуйтеся з Губкою Бобом, Патріком, Сквідвардом або Намбер Ваном. Кожен герой має свій неповторний характер.
*   **🧠 Запитати в Розумника:** Отримуйте лаконічні та зрозумілі відповіді на будь-які запитання від самого Губки Боба.
*   **🎮 Ігри та розваги:**
    *   **🔢 Вгадай число:** Спробуй відгадати, скільки бульбашок загадав Губка Боб.
    *   **✂️ Камінь, ножиці, папір:** Класична гра проти бота.
    *   **❌⭕️ Хрестики-нулики:** Морська версія популярної гри.
*   **🐙 Морська вікторина:** Перевір свої знання у веселій вікторині з поясненнями від Губки Боба.
*   **🌐 Морський перекладач:** Перекладай фрази на англійську, українську або російську мови.
*   **🧮 Рахуємо бульбашки:** Зручний калькулятор для маленьких математиків.
*   **🎲 Випадкова цікавинка:** Дізнавайся нові неймовірні факти щодня.

## 🛠 Технології

- **Python 3.10+**
- **python-telegram-bot:** для взаємодії з Telegram API.
- **OpenAI API (GPT-3.5 Turbo):** для генерації тексту та логіки персонажів.
- **SQLite:** для збереження профілів користувачів та їхніх налаштувань.
- **Pytest:** для тестування функціоналу.

## 📦 Встановлення та запуск

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-repo/tg_bot_sponge_bob.git
   cd tg_bot_sponge_bob
   ```

2. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Налаштуйте змінні оточення:**
   Створіть файл `.env` (або відредагуйте `src/config.py`) та додайте ваші токени:
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   CHATGPT_TOKEN=ваш_openai_api_key
   ```

4. **Запустіть бота:**
   ```bash
   python src/bot.py
   ```

## 🧪 Тестування

Для запуску тестів використовуйте:
```bash
pytest
```

## 👤 Персоналізація

При першому запуску (`/start`) бот запропонує дитині познайомитися. Він запам'ятовує:
- Ім'я дитини
- Стать (для коректних звернень героїв)

Ці дані надійно зберігаються в базі даних і використовуються в усіх режимах для створення максимально дружньої атмосфери.
